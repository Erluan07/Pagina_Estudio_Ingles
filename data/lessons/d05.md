## Read in Daily Life: leer rápido textos cotidianos

**Qué es.** Textos breves de la vida real: avisos, correos, anuncios, menús, horarios, mensajes de grupo. Las preguntas piden **propósito, detalle, inferencia simple y condiciones** (*who/when/what must*).

### Estrategia: lee las preguntas «con intención» y escanea
1. **Mira el formato** (asunto, remitente, título): ya te da el propósito.
2. **Lee las preguntas primero** (30 s) para saber qué datos buscar: fechas, horas, plazos, requisitos.
3. **Escanea** el texto buscando esos datos (números, nombres propios, palabras de condición: *must, only if, unless, no later than*).
4. **Cuidado con las trampas**: horarios distintos para días distintos (*weekdays / weekends*), excepciones (*except*), cambios (*moved to*).

### Tipos de pregunta y cómo contestarlas
| Tipo | Pista | Ejemplo |
|---|---|---|
| Propósito | Asunto + primera frase | *Why did the writer send this message?* |
| Detalle | Dato exacto | *What time does…?* |
| Condición | *only if, unless, must* | *What is required to…?* |
| Inferencia | Lo que se sugiere | *What can be inferred about…?* |
| Vocabulario | Sinónimo en contexto | *«lapse» is closest to…* |

### Vocabulario de avisos
**mandatory** (obligatorio), **eligible** (con derecho a), **deadline**, **in advance**, **no later than**, **be refunded**, **applicable fee**, **residents**, **attendees**.

> **Práctica de hoy:** tres textos (aviso de residencia, correo de un profesor, promoción de cafetería), 3 preguntas cada uno.
